# 猫窝 More · 给朋友的安装说明

一个跑在你自己电脑上的 WorkBuddy 后勤小工具。免费，不上传任何东西。

## 它帮你做什么

- 把几个 WorkBuddy 账号收进一个名册，余额、连续打卡天数一眼看清
- 一键批量打卡；到站猫猫的俸禄一键领取
- 自动派猫旅行、到点自动领（默认关闭，想开再开）
- 把 WorkBuddy 的模型以 OpenAI 兼容接口在本机反代出来，接到任意支持自定义模型的客户端

## macOS 安装

1. 从 [Releases](https://github.com/hindleycheng/more/releases) 下载对应芯片的 `.dmg`：
   - Apple 芯片（M1/M2/M3/M4）→ `More_x.y.z_aarch64.dmg`
   - Intel → `More_x.y.z_x64.dmg`
   - 不确定：点左上角  → 「关于本机」，看到 "M" 开头就选 Apple 芯片版。
2. 双击打开 dmg，把 **More** 图标拖进「应用程序(Applications)」文件夹。
3. 第一次打开如果提示 **"More 已损坏，无法打开"**：这是正常现象。这个工具没有花 $99/年买 Apple
   开发者证书做签名和公证，所以 macOS 会给下载来的 App 打个"隔离标记"。文件本身没问题。
   打开「终端」，执行这一行就好（永久生效，只清除标记，不改动程序内容）：

   ```bash
   xattr -cr /Applications/More.app
   ```

   如果提示权限不足，用这条：

   ```bash
   sudo xattr -rd com.apple.quarantine /Applications/More.app
   ```

   也可以试试：在「应用程序」里**右键点击 More → 打开 → 再点"打开"**，绕过一次性安全提示。
4. 打开后先读一屏「知情同意」，点「我明白了，进入猫窝」。
   在你点之前，这个程序不会联网、不会启动任何后台任务。
5. 进「猫口名册」→ 网页授权登录，把你的 WorkBuddy 账号加进来。

## Windows 安装（64 位，Win10 / Win11）

两种任选：

- **免安装绿色版** `More.exe`：放进任意文件夹（例如 `D:\More\`）双击即可。
  需要系统装有 WebView2 运行时——Win11 自带，多数更新过的 Win10 也有；
  若双击后窗口空白或提示缺组件，去微软官网装一次 "Evergreen WebView2 Runtime" 即可。
- **安装包** `More_x.y.z_x64-setup.exe`：双击装到「应用」里，之后从开始菜单启动。

首次运行如果 SmartScreen 拦一下（因为没花 $99 买代码签名证书），点「更多信息」→「仍要运行」。

> 说明：Windows 包已在真机（Windows 11 x64 + WebView2 155）上跑通：主界面正常显示、
> 托盘能唤回窗口、日志落盘正常。装完如果双击没反应、或者窗口白屏，先看这条：
> 程序会在 25 秒内自检，发现界面没渲染出来会自动切到软件渲染（禁用图形加速）重启一次；
> 仍然不行会弹窗告诉你原因，并把日志写在 `%APPDATA%\More\logs\more.log`——把那个文件发给作者即可。

## 你的数据在哪

- macOS：`~/Library/Application Support/More`
- Windows：`%APPDATA%\More`

登录凭证用一把**首次运行时在你本机随机生成**的密钥加密后才落盘（密钥文件权限 0600）：
不进安装包、不上传、换一台机器也解不开。安装包发给别人时是一个空白的全新程序，不会带任何人的账号。

说清楚它的边界：这把密钥挡住的是「安装包到处传、结果人人能解密」和同机其它普通用户，
**挡不住** root、以你身份跑的其它程序、以及你把整个数据目录一起备份/同步出去造成的泄露。
想要更强保护：给这块磁盘开 FileVault，并且别把 `More` 数据目录放进 iCloud / 网盘同步。
（这里没用系统钥匙串是有原因的：本工具未做付费签名，用钥匙串会导致每次升级都弹一次
「请输入登录钥匙串密码」，还会卡住程序——实测过，不划算。）

想彻底清除：删掉 App，再删掉上面那个目录。想先断凭证但保留名册：「窝规」→「抹掉登录凭证」。

## 关于自动化，说句实话

自动打卡和自动派猫旅行，本质是让程序按时替你操作账号。多数服务的条款并不欢迎这个，
理论上可能触发限流或风控。所以这一版里：

- 所有自动化**默认关闭**，需要你在「窝规」里逐项自己打开
- 旅行托管带当日熔断，不会无上限轮询官方接口
- 别把不想承担风险的账号（公司号、付费主力号）交给它

用不用、用哪个号，是你自己的决定。

## 它不是官方产品

猫窝是第三方独立开发的本地工具，与 WorkBuddy 官方无关，也未获其授权或背书。

## 常见问题

**反代怎么接到别的客户端？** 工具间 → 本地反代 → 填一个至少 16 位的 API Key（旁边有「一键生成」）→ 打开开关。
会拿到一个 `http://127.0.0.1:端口/v1` 的地址，填进任何支持「自定义模型 / OpenAI 兼容接口」的客户端就行。
Key 不填或者地址填了 `0.0.0.0`，猫窝会拒绝启动并把原因告诉你——这是故意的，防止你的额度被同网络的其它设备白嫖。

**端口冲突起不来？** 换一个端口（1024–65535），界面会写明是哪个端口被占了。

**「窝规」里的诊断落盘是什么？** 排查用的：开了之后会把接口原始响应写成明文 JSON，里面包含你的提问原文。
默认关闭，用完记得关掉并点「清理诊断快照」。

**要不要升级？** 数据目录不变，下新版本覆盖 `/Applications/More.app` 就行，账号需要重新授权一次的情况会在说明里写清。
